# GitHub Repo Search

Search GitHub repositories. Built with Vue 3, Vite, TypeScript, and Vuetify.

## Setup

```sh
npm install
```

## Development

```sh
npm run dev       # dev server with hot reload
npm run build     # type-check + production build
npm run preview   # preview production build
```

## Testing

```sh
npm run test:unit        # Vitest unit tests
npm run test:component   # Cypress component tests
npm run test:e2e         # Cypress E2E (starts server automatically)
```

## Lint & Format

```sh
npm run lint    # oxlint + ESLint
npm run format  # Prettier
```

## CI

Push or PR to `main` triggers GitHub Actions running lint, type-check, unit tests, component tests, E2E tests, and build.

Auto-deployed to Vercel. Production from `main` at <https://pbsabella-github-repo-search.vercel.app>, preview deployments for PR branches.
